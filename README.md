# アルハンブラ宮殿さんぽ

スペイン・グラナダのアルハンブラ宮殿を、スマホで歩いて巡る3D散策。
世界さんぽシリーズ（ヴェルサイユ宮殿さんぽ・ノイシュヴァンシュタイン城さんぽ）と同じ操作系（three.js r128・単一HTML）。

- 森と門：アルハンブラの森（ニレの坂道）、ザクロの門、カルロス5世の泉（ピラール）、裁きの門（手と鍵の印）
- アルカサバ：武器の広場（兵の町の土台）、ベラの塔（東の扉で「上る／下りる」、塔の上からグラナダとシエラ・ネバダ）、主塔・崩れの塔
- 貯水槽の広場、ワインの門
- ナスル朝宮殿：メチューカの中庭 → メスアールと礼拝室 → 黄金の間の中庭とコマレスの正面 → 曲がった通路 → アラヤネスの中庭（池にコマレスの塔が映る）→ 舟の間 → 大使の間（杉の寄木の天井「七つの天」）／ライオンの中庭（124本の柱・12頭のライオンの泉・東西のあずまや・十字の水路）、アベンセラーヘスの間・二姉妹の間（ムカルナスのドーム）、アヒメセスの間とリンダラハのミラドール、王たちの間（天井画）、リンダラハの庭 → 出口からパルタルへ
- カルロス5世宮殿（四角の中の円い中庭、2階建ての列柱）、ラウダ（王家の墓所）、モスク／サンタ・マリア教会、上の町（メディナ）とカジェ・レアル、サン・フランシスコ修道院
- パルタル（貴婦人の塔と池・石のライオン・段々の庭）、塔の小道
- ヘネラリフェ（東の門から橋を渡る）：アセキアの中庭（水路と噴水のアーチ）、西の回廊（18のアーチ越しにアルハンブラ）、王の間と見晴らしの塔、スルタナの糸杉の中庭、水の階段、新しい庭
- まわり：ダロ川の谷、アルバイシンとグラナダの町の白い家並み、南東にシエラ・ネバダの雪の峰
- とき：ナスル朝の時代（1370年ごろ・漆喰が青赤緑金に彩色、カルロス5世宮殿はなく町の家並み、リンダラハの庭は谷に開ける、赤い旗）／カルロス5世の時代（1530年ごろ・円い宮殿が工事中、ベラの鐘、カスティーリャの旗）／現在
- 時刻：朝・昼・夕（城壁が赤く染まる）・夜（城壁のライトアップ、アルバイシンの窓の灯り、星）、噴水の出す／止める
- 見どころ札集め（全32か所・歩いて訪れたときだけ。localStorage `alhambra_fuda`）、獅子の中庭の印（`alhambra_seal`）、写真モード、道案内（光の矢印）、合成音（丘の風・噴水と水路・宮殿の中のウード風の旋律・ベラの鐘・アマツバメ）

建物や庭園は写真や資料をもとにした簡略な再現で、部屋の数や大きさ、建物どうしの距離は歩きやすく整えています。方角はおおむね実際どおり（北がダロ川の谷とアルバイシン、南東がシエラ・ネバダ）。
